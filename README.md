# Vietify-Chrome

Chrome extension for vietify.

**Give foreign pronunciation a Vietnamese-style spelling.**

This extension converts Pinyin or IPA (International Phonetic Alphabet) into Vietnamese-inspired phonetic spelling.

It can phonemize:

* English (Great Britain/American/Australian")
* French
* German
* Russian
* Mandarin Chinese (Pinyin)
* Japanese
* Korean
